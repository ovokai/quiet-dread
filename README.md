My entry for the make.fun competition **Two Days of Quiet Dread**: a single-line code review comment that approves a pull request while carrying quiet existential dread.

> Approved. This will outlive every one of us, which is either the code's best feature or its quietest threat.

Running `main.ts` (Node, standard library only) writes the comment to `/output/entry.txt`, falling back to a local `entry.txt` when `/output` is not writable.
